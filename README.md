# CardioResearch — приложение для дипломного исследования

Актуальный программный проект: [CardioResearch_3.0](CardioResearch_3.0/), версия приложения **3.2.0**. Имя папки сохранено для совместимости. Репозиторий: [Aidana17022007/diplom](https://github.com/Aidana17022007/diplom), ветка `main`.

## Что добавлено в 3.2

- **Сравнение моделей**: 13 метрик, включая balanced accuracy, MCC, NPV, FPR и FNR; справочник RU/KK, правильное направление сравнения, CSV с методикой и SVG для всех показателей. Метрики UCI вычисляются отдельно в каждом фолде, затем усредняются; неопределённые значения остаются пустыми.
- **Диагностика → Глубокий анализ**: накопленный охват положительных случаев, precision и lift при выборе верхних оценок; метрики по числу пропусков; объяснение выбора BRFSS-модели по validation с отдельными результатами test.
- **Эксперименты ML → Улучшение моделей**: выполнено свежее обучение четырёх конфигураций на 36 000 строк исходного fit, с общими тремя фолдами. Показаны результаты каждого фолда, средние/SD, парные изменения AP и диагностические ошибки при пороге 0.5. Протокол сохранён до обучения; исходные calibration/validation/test не использовались в этом опыте.

LightGBM с 7 листьями дал AP 0.317151 против 0.316295 у LR: **+0.086 процентного пункта**, положительная разность только на **1 из 3 фолдов**. Это не подтверждает устойчивое улучшение. Рабочая модель, её порог и исходная оценка качества сохранены. На сохранённом BRFSS test верхние 10% оценок охватывают 40.83% положительных случаев; это описательная характеристика ранжирования, не новая валидация.

## Сохранённые возможности 3.1

- **Эксперименты ML → Аудит ML**: точность SHAP против полного перебора, влияние доли класса на AP/Precision, диагностика калибровки и парный опыт с индикаторами пропусков. Интерактивные графики, таблицы, JSON с протоколами и SHA-256 исходных отчётов.
- **Дашборд**: раскрываемые сохранённые интервалы Уилсона, точные знаменатели и доступная с клавиатуры таблица калибровки. BRFSS test и UCI OOF остаются разными схемами оценки.
- **Атлас артерии**: режим 2D без WebGL, PNG схемы и возврат в 3D с сохранением геометрии. Сбой загрузки 3D не отключает остальные инструменты.
- **Запуск**: проверка Python 3.12, моделей, прогнозов и файлов интерфейса перед открытием браузера; понятная ошибка занятого порта. Исправлен отсутствующий JSON, мешавший локальной сборке.

Исходные модели, пороги и основные экспериментальные результаты сохранены; новые конфигурации обучались отдельно. Изменения этого выпуска относятся к программному проекту; рукопись диплома не дорабатывалась.

## Запуск на этом компьютере

Откройте **START_RESEARCH.cmd**. Скрипт проверит окружение и откроет полное приложение на `http://127.0.0.1:8000/#experiments`. Окно запуска должно оставаться открытым; остановка — Ctrl+C.

Для другого порта или явного окружения:

```powershell
cd CardioResearch_3.0
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Port 8001 -PythonPath "C:\path\to\venv\Scripts\python.exe"
```

## Установка после скачивания

Установите Python 3.12, распакуйте [архив приложения 3.2](CardioResearch_3.2_app_20261117.zip) и выполните в извлечённой папке `CardioResearch`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\START.cmd
```

Архив содержит готовый интерфейс, Python/React-исходники, модели, проверенные обработанные данные UCI/BRFSS и исследовательские отчёты. Node.js для работы готового локального приложения не нужен. Python-пакеты устанавливаются при первом запуске setup; архив не содержит виртуального окружения. Исторические выпуски и материалы диплома сохранены отдельно в репозитории.

## Проверка и воспроизводимость

- `CHECK.cmd` — проверки Python и доступности приложения.
- `python scripts/export_scientific_audit.py` — повторная выгрузка агрегатов из сохранённых аудитов без обучения.
- `python scripts/build_metrics_insights.py` — анализ зафиксированных прогнозов без переобучения, с проверкой соответствия исходным наблюдениям и хешей.
- `python scripts/development_study.py` — воспроизведение отдельного опыта на исходной обучающей части; перезаписывает только его протокол и результаты.
- `python scripts/package_release.py --output C:\absolute\path\release.zip` — новый ZIP без перезаписи старых выпусков, с проверкой хешей обработанных таблиц и согласованности двух интерфейсов.
- `deployment/cardio-site`: `npm ci`, `npm --prefix client ci`, `npm run build`, `npm test` — сборка и проверки веб-демо.

Фактические результаты проверок выпуска: [release_3_2_validation.json](CardioResearch_3.0/reports/release_3_2_validation.json): 117 Python-тестов и 85 Worker-тестов; обе сборки прошли. Браузерная проверка новых экранов в этом выпуске недоступна. Перечень опубликованных файлов и SHA-256: [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json).
