# CardioResearch 3.0

Полный проект: [CardioResearch_3.0/](CardioResearch_3.0/). Готовый архив: [CardioResearch_3.0_verified_20261117.zip](CardioResearch_3.0_verified_20261117.zip). Репозиторий: [Aidana17022007/diplom](https://github.com/Aidana17022007/diplom), ветка `main`.

После установки запустите `START_RESEARCH.cmd`, затем откройте http://127.0.0.1:8000/#experiments. Команда использует окружение проекта `.venv`, а на исходном компьютере также поддерживает ранее проверенное локальное окружение. Окно сервера должно оставаться открытым. `START_SITE.cmd` показывает веб-демо после его сборки; обучение в демо отключено.

Для запуска после клонирования установите Python 3.12 и выполните в PowerShell:

```powershell
cd CardioResearch_3.0
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\START.cmd
```

Готовый интерфейс и обработанные данные уже включены. Node.js для запуска Python-приложения не требуется. `REPRODUCE.cmd` загружает исходные данные из проверенных источников и запускает исходные Python-тесты. При использовании ZIP команды выполняются внутри извлечённой папки `CardioResearch`.

В репозитории находятся исходники Python и React/TypeScript, сохранённые модели, данные UCI/BRFSS, отчёты и журнал экспериментов, тесты, документация, готовый интерфейс, материалы диплома и все 17 сохранённых ZIP/tar.gz-архивов. Перечень файлов и SHA-256: [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json). Временные окружения, скачанные пакеты, кэш исходных данных и дублирующие рабочие каталоги исключены; скрипты воспроизведения включены.

В версии 3.0 добавлены:

- Реальное локальное обучение Logistic Regression и Random Forest с прогрессом, отменой и сохранением результатов.
- Четыре рассчитанных эксперимента: кривые обучения, дополнительные пропуски, числовой шум и удаление признаков. Новый протокол из трёх фолдов отделён от исходных оценок моделей.
- Матрица разногласий восьми алгоритмов UCI и разбор общих ошибок.
- Перенос фиксированной BRFSS-модели на 452 464 наблюдения 2024 года с контролем двух отсутствующих признаков на тесте 2023.
- Синхронное сравнение двух 3D-артерий, общий ракурс и PNG обоих видов.
- Точные восстановленные таблицы UCI/BRFSS, включённые в полный проект и ZIP.
